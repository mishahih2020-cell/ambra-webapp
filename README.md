# Горчит — Telegram WebApp

Рабочее веб-приложение магазина табака и кальянной продукции. Дизайн — тёмная тема (латунь/золото на тёплом тёмном фоне), структура экранов — как в согласованном дизайн-концепте.

Никакой сборки не требуется: чистые HTML/CSS/JS, один SPA на хэш-роутинге.

## Как запустить локально

```
node serve.js
```

Откройте http://localhost:8123 в браузере (в мобильном режиме DevTools для проверки на телефонном экране).

## Структура

```
index.html        — точка входа, подключает Telegram WebApp SDK
css/style.css      — дизайн-система (токены, компоненты, экраны)
js/data.js          — каталог, заказы, промокоды (моковые данные — заменить на API)
js/app.js           — роутинг, состояние (корзина/избранное), рендер всех экранов
serve.js            — локальный сервер для разработки (не нужен в проде)
```

## Экраны

Онбординг (18+) → Каталог → Категория → Поиск → Карточка товара → Корзина → Оформление заказа →
Подтверждение заказа → Профиль → История заказов → Детали заказа → Акции и бонусы → Избранное →
Колесо фортуны → Реферальная программа.
Пустые состояния (корзина/поиск/заказы) встроены в соответствующие экраны.

## Лояльность и кешбэк

Три уровня (Silver / Gold / Platinum), кешбэк начисляется бонусами на каждый оплаченный заказ
по проценту текущего уровня, уровень растёт по накопленной сумме покупок (`js/data.js → TIERS`).
Бонусы можно списать при оформлении заказа (до 30% от суммы товаров).

## Реферальная программа

Каждому пользователю генерируется персональный код (`GRCH-XXXXXX`) и ссылка вида
`?ref=КОД`. Экран «Пригласить друзей» — кнопки «Поделиться» (через Telegram) и «Скопировать
ссылку». Начисление бонусов за приглашённых сейчас на стороне бэкенда не реализовано
(список приглашений в `js/data.js → REFERRALS` — заглушка для демонстрации UI).

## Колесо фортуны

1 бесплатная прокрутка в день + 1 прокрутка за каждый оформленный заказ. Призы и их веса —
`js/data.js → WHEEL_PRIZES / WHEEL_WEIGHTS` (бонусы, промокод, бесплатная доставка, лишняя попытка).

## Каталог и фото

Категории: Табак, Кальяны, Угли, Чаши, Аксессуары, Жидкости для вейпа. Фото товаров —
реальные изображения со свободной лицензией (Wikimedia Commons, `Special:FilePath`,
без ключей и без внешних сервисов), подобранные по категории товара — это наглядные
фотографии, а не студийная съёмка конкретного SKU. Перед боевым запуском замените
`PHOTO`/`image` в `js/data.js` на настоящую съёмку каталога.

## Состояние и данные

Корзина, избранное, бонусный баланс, промокоды и прокрутки колеса хранятся в `localStorage`
браузера пользователя. Каталог, заказы, промокоды, уровни лояльности и призы колеса — в
`js/data.js`; при подключении бэкенда замените константы там на реальные запросы к API
(структура объектов уже соответствует тому, что использует рендер).

## Telegram WebApp

Подключён официальный SDK (`telegram-web-app.js`). При запуске внутри Telegram:
- автоматически разворачивается на весь экран (`expand()`);
- цвет шапки/фона подстраивается под тёмную тему приложения;
- кнопка «Назад» в Telegram используется для навигации между вложенными экранами;
- лёгкая вибрация (haptics) на ключевых действиях (добавление в корзину, оформление заказа).

Вне Telegram (обычный браузер) всё работает так же — SDK просто не активируется.

## Деплой

Разместите содержимое папки на любом статическом хостинге (Vercel, Netlify, GitHub Pages, свой сервер)
и укажите публичный HTTPS-адрес в настройках Mini App у @BotFather.
